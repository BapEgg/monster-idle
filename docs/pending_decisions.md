# 결정 대기 목록

Claude가 임시로 정했거나 물어봤는데 아직 답을 받지 못한 것을 모아 둔 곳이다(사용자 요청 2026-10-03: 나중에 한 번에 보고 결정).

- **Claude가 관리한다.** 보고의 "임시로 정한 것" 가운데 사용자 답이 필요한 것은 여기에도 덧붙인다.
- 답을 받으면 그 줄을 `CLAUDE.md` 사용자 결정 표로 옮기고 여기서는 지운다.
- 답할 때는 번호로 말하면 된다. 예: "A1 레시피 단서로", "B 표는 그대로", "E2 지움".
- 지금 값은 모두 실제로 돌아가는 값이다. 답이 없으면 이대로 둔다.

## L. 종족 상성표 추천안 (2026-10-03, 사용자 요청 10 — 답을 받으면 만든다)
